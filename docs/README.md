# Documentation

Every page in this folder is documentation for someone using the library, and
nothing else belongs here: the design record — the specification — is in the
repository's [`design` folder](https://github.com/jinaga/jinaga-worker/tree/main/design),
and the constitution it answers to is the
[`degrees-of-freedom` skill](https://github.com/michaellperry/skills/tree/main/skills/degrees-of-freedom).
That rule is what lets the whole folder be published with the package.

These pages travel with the package, so a page here reaches anything outside it
by absolute URL, and by relative path only within the folder.
